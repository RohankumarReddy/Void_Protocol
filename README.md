A minimal, real-time anonymous chat application designed for private, temporary communication.  
Rooms support exactly two participants and are automatically destroyed after a defined duration or on manual purge.

## Features

- Real-time, low-latency messaging
- Anonymous access with no authentication
- Strict two-user room limit
- Ephemeral rooms with automatic expiration
- Immediate room invalidation via purge
- Shareable room ID for direct access
